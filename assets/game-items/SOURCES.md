# Valheim icon references

Extracted read-only from the locally installed Valheim 1.0.12 game using UnityPy 1.25.3. Artwork belongs to Iron Gate; these are actual inventory sprites, not generated replacements.

Source: `valheim_Data/StreamingAssets/SoftRef/Bundles/6a33a62`, mapped by `SoftRef/manifest_extended` to `Assets/GameElements/Items/_icons/`.

References extracted: copperore, carrot, mushroom, thistle, obsidian and raspberry (64×64 Sprite assets). Used as visual references for the revised WildGlow branding icon. The complete reference set is not bundled into the mod ZIP.
